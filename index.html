BaseLib Settings

Live Pack Switches

Every character and card type is its own pack. Open the mod settings from the BaseLib menu, switch any pack off under Card packs, and the change shows at once — even on cards already on screen, which get the game's original portrait layout back.

  • Toggle any of the 12 bundled packs — or packs from other mods — independently.
  • Adjust or disable parallax depth, enable Reduced Motion, or switch to flat full art without layers.
  • Turn rarity finishes off, fade their strength, or swap finish styles.
  • Press F8 while hovering a card to write a local report for bug reports.

Pack Format v2

For Mod Authors

Other mods can ship full art for their own cards without touching Full Art Spire's folder. Drop a pack under full_art/<pack>/pack.json inside your mod — or in the player's full_art_spire/packs/ directory — and match cards by their full .NET runtime_model type name.

  • JSON Schema (docs/pack.schema.json) provides editor completion and inline errors.
  • tools/validate_pack.py checks manifest fields, confined paths, layers and GPU textures.
  • Optional requires and min_game_version gates skip packs cleanly when a dependency is absent.
Read Pack Format Docs Schema & Validator on GitHub
full_art/my_character/pack.json Pack Format v2 
{
  "format": "full_art_pack",
  "format_version": 2,
  "id": "author.my_character",
  "name": "My Character",
  "version": "1.0.0",
  "requires": [{ "mod": "my_character_mod" }],
  "cards": [
    {
      "runtime_model": "MyMod.Cards.ExampleCard",
      "art": "art/example_card.png",
      "layers": {
        "background": "layers/example_card_bg.png",
        "foreground_mask": "layers/example_card_mask.png"
      }
    }
  ]
}

Transparency & Notes

How It's Made

Clear details on how the full-art extensions, depth layers and packaged files are produced.

AI-generated extensions & backgrounds

The full-art extensions and depth-layer backgrounds are AI-generated (OpenAI image models), starting from Mega Crit's original card art and reviewed against it.

Re-encoded release images

Released images are re-encoded to save space, which removes the C2PA Content Credentials the image generator embedded.

Cutouts & edge artifacts

Some foreground cutouts may show small edge artifacts. If you spot one in game, press F8 while hovering the card to save a local report and share it with a screenshot.
